# SkillBridge — AI Career Development Platform

Платформа, которая помогает перейти от текущего набора навыков к желаемой профессии:
анализ CV → реальные вакансии → Skill Gap → персональный Roadmap → практические задания → прогресс.

> **Real Job Market → Skill Gap Analysis → Personalized Roadmap → Learning → Practical Assessment → Updated Skills → Better Job Matches**

Полная спецификация: [docs/SPECIFICATION.md](docs/SPECIFICATION.md)

## Структура

```
skillbridge/
├── backend/            # Java + Spring Boot (модульный монолит, REST, JWT)
├── frontend/           # Next.js + TypeScript + Tailwind + shadcn/ui
├── docs/               # Спецификация и документация
└── docker-compose.yml  # PostgreSQL + pgvector
```

## Быстрый старт

```bash
cp .env.example .env
docker compose up -d postgres   # порт 5434 (POSTGRES_PORT)

# backend
cd backend && ./mvnw spring-boot:run

# frontend
cd frontend && npm install && npm run dev
```

## MVP (хакатон)

1. Регистрация / демо-профиль
2. Загрузка CV (PDF)
3. Извлечение опыта и навыков с помощью AI
4. Выбор одной целевой профессии
5. Реальные вакансии из одного источника (hh.kz API)
6. Сопоставление навыков с требованиями вакансий
7. Skill Gap
8. Персональный Roadmap
9. Учебные материалы с проверяемыми ссылками
10. Отслеживание выполнения учебных задач

## Извлечение данных из CV

- Если задан `OPENAI_API_KEY` — структурированное извлечение через OpenAI (strict JSON schema,
  `backend/src/main/resources/ai/resume-schema.json`), ответ валидируется и нормализуется на backend.
- Без ключа (или при ошибке AI) — fallback: поиск навыков из каталога по ключевым словам.
  Опыт и образование при этом не угадываются — пользователь заполняет их на шаге проверки.
- Навыки сопоставляются с каталогом по названию и синонимам; несопоставленные возвращаются в
  `unmatchedSkills` и не сохраняются, пока пользователь не выберет навык из каталога (`skillId`).
- Уровень навыка из CV — оценка (`CV_EXTRACTED`, `proven: false`), а не подтверждённый результат.

Демо-CV для сценария хакатона: [docs/demo/demo-cv.pdf](docs/demo/demo-cv.pdf) (вымышленный человек).

## Вакансии и Job Matching

- **hh.kz**: официальный API (`api.hh.ru`, area=40 Казахстан). Поиск вакансий требует токен приложения
  (анонимно — 403): зарегистрируйте приложение на https://dev.hh.ru и задайте `HH_APP_TOKEN`
  или `HH_CLIENT_ID`/`HH_CLIENT_SECRET`. Импорт: admin-эндпоинт или ежедневно в 06:00
  (`HH_SCHEDULE_ENABLED=true`). Роль ADMIN выдаётся email-ам из `ADMIN_EMAILS`.
- **Remotive и Himalayas** (открытые API, ключ не нужен): международные удалённые вакансии любых регионов; регион
  виден в карточке («Удалённо · USA»), Казахстан в списке стран показывается первым. `REMOTE_JOBS_ONLY_OPEN_TO_KZ=true`
  оставляет только вакансии, доступные из Казахстана. Поиск у API нестрогий, поэтому вакансия попадает
  в профессию только если её **название** совпадает с ключевыми словами профессии (`professions.title_keywords`).
  Импорт при старте (если таких вакансий ещё нет) и ежедневно в 06:30; не обновлявшиеся 14 дней — в архив.
  Зарплата: диапазон с периодом (`/год`, `/мес`) или текст источника как есть. В интерфейсе — подпись источника и
  ссылка «Открыть на Remotive/Himalayas» (требование условий API).
- **Telegram-канал команды**: бот (`TELEGRAM_BOT_TOKEN`) добавляется администратором канала
  (`TELEGRAM_CHANNEL`) и получает новые посты через `getUpdates` (`TELEGRAM_POLLING_ENABLED=true`, раз в 30 с).
  Bot API не читает историю — старые посты импортируются из экспорта Telegram Desktop (JSON).
  Посты по шаблону разбираются точно; свободные посты — через AI (если задан ключ), иначе пропускаются.
  Ссылка на источник — внешняя ссылка из поста или сам пост `t.me/...`. Шаблон поста:
  ```
  #вакансия
  Должность: Junior Data Analyst
  Компания: Example
  Город: Алматы
  Зарплата: 400 000–600 000 KZT
  Опыт: 1–3 года
  Формат: гибрид
  Требования: SQL, Excel, Power BI
  Желательно: Python
  Ссылка: https://...
  ```
- Требования извлекаются детерминированно: `key_skills` → обязательные; навыки каталога в тексте —
  обязательные, а под заголовком «Будет плюсом / Желательно» — желательные.
- **Формула совпадения**: `Σ(weight × credit) / Σ(weight) × 100`, weight = 2 (обязательный) / 1 (желательный),
  credit = min(уровень пользователя / требуемый уровень, 1). Результат проверки (ASSESSED) важнее CV.
  Ответ содержит совпавшие, частичные и отсутствующие навыки — это оценка соответствия, а не вероятность найма.
- Отсутствующие в источнике зарплата/опыт возвращаются как `null` («не указано»).

## Skill Gap, Roadmap, прогресс

- **Skill Gap**: при ≥ 5 проанализированных вакансиях важность навыка считается по доле вакансий, где он встречается
  (`MARKET`), иначе — по базовым требованиям профессии (`BASELINE`). Статусы: сильная сторона / нужно улучшить /
  большой пробел. Приоритет = важность × отставание.
- **Job Readiness Score**: `Σ(важность × min(уровень/требуемый, 1)) / Σ(важность)`; отдельно `provenScore` — только по
  навыкам, подтверждённым заданиями. Ориентир, а не вероятность трудоустройства.
- **Roadmap**: до 6 приоритетных пробелов + их недостающие пререквизиты (например, отчётность → анализ → моделирование →
  оценка), итоговый проект. В каждом модуле: цель, темы, оценка времени (~10 ч на уровень), критерии завершения,
  связь с вакансиями и реальные материалы.
- **Материалы**: 51 ресурс с проверенными ссылками (миграция V4); `LinkChecker` перепроверяет их еженедельно и скрывает
  недоступные. Время обучения не отслеживается, поэтому и не показывается.

## Практические задания

- **Тесты (QUIZ)** и **SQL-задачи** проверяются объективно; **развёрнутые ответы** — AI по фиксированной рубрике
  (без ключа OpenAI ответ сохраняется со статусом `PENDING`). Порог прохождения — 70%.
- **SQL-песочница**: запрос пользователя выполняется под отдельной ролью БД `skillbridge_sandbox` без привилегий
  (только `SELECT` на синтетической схеме `sandbox`), в read-only транзакции, с таймаутом 3–5 с и лимитом 500 строк;
  разрешён ровно один `SELECT`/`WITH`. Результат сравнивается с эталонным запросом.
  Пароль роли — `SANDBOX_DB_PASSWORD` (задаётся при первой миграции V5).
- Пройденное задание повышает уровень навыка с источником `ASSESSED` (никогда не понижает), закрывает модуль Roadmap,
  когда подтверждённый уровень достигает целевого, и пересчитывает Skill Gap / Job Matching / readiness.

## База данных

Миграции Flyway: `backend/src/main/resources/db/migration`
- `V1__init_schema.sql` — все сущности из спецификации (§9)
- `V2__seed_catalog.sql` — 4 MVP-профессии, каталог навыков и базовые требования
- `V3__resume_parser.sql` — тип парсера CV
- `V4__learning_content.sql` — темы обучения по навыкам и учебные материалы
- `V5__challenges_and_sandbox.sql` — SQL-песочница, учебный датасет и 17 практических заданий
- `V6__remote_job_sources.sql` — период/текст зарплаты, признак удалённой работы, ключевые слова профессий
